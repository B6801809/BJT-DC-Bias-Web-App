# Reflection — Lab 02

## สิ่งที่ได้เรียนรู้

- ความแตกต่างระหว่าง Static HTML กับ Web Application ที่มี Backend จริง
- การแยก Engineering Logic (`dc_bias.py`) ออกจาก Web Layer (`app.py`) ทำให้ทดสอบง่ายและลดการผูกติดกับ framework
- การจัดการหน่วยเป็นจุดที่ผิดพลาดได้ง่าย (kΩ vs Ω) จึงต้องแปลงให้ชัดเจนที่ขอบระบบ
- การทำ Validation และ Warning ทำให้โปรแกรมซื่อสัตย์ต่อข้อจำกัดของแบบจำลอง
- การวาดภราฟด้วย SVG ที่เขียนเองทำให้ไม่ต้องเพิ่ม dependency และ
  ยังตรวจสอบความถูกต้องของจุด Q บน load line ได้ด้วย automated test
- การวาด load line ที่รวมผลของ RE (ผ่าน IE = IC·(β+1)/β) ทำให้จุด Q บนกราฟ
  ตรงกับค่าที่คำนวณได้เสมอ เป็นการตรวจสอบสมการด้วยอีกวิธีหนึ่ง
- การให้ผู้ใช้เลือกหน่วยได้ ทำให้ใช้งานกับข้อมูลจริงได้หลากหลาย แต่ต้องแยก
  "หน่วยที่แสดง" ออกจาก "หน่วยที่คำนวณ" — ถ้าปนสองอย่างนี้จะเกิดบั๊กคลาสสิก
  แบบเดียวกับที่เคยเจอ (kΩ กับ Ω)

## ปัญหาที่พบและวิธีแก้

1. **ModuleNotFoundError: No module named 'flask'**
   - สาเหตุ: รันด้วย Python ระบบที่ยังไม่ได้ติดตั้ง Flask
   - แก้ไข: สร้าง virtual environment แล้ว `pip install -r requirements.txt` และ activate ก่อนรันทุกครั้ง
2. **Activate venv ด้วย path ผิดรูปแบบ (`/c:/...`)**
   - สาเหตุ: ใช้ path แบบ Git Bash ใน PowerShell
   - แก้ไข: ใช้ `.\.venv\Scripts\Activate.ps1`
3. **หน่วยความต้านทานไม่ตรงกัน**
   - สาเหตุ: ฟอร์มเป็น kΩ แต่ backend ตีความเป็น Ω
   - แก้ไข: คูณ 1000 ใน `app._parse_inputs`
4. **Cutoff/Saturation แสดงค่าติดลบ**
   - แก้ไข: จัดการ Cutoff แยกและคืนกระแสศูนย์ พร้อม Warning
5. **ป้ายบนภาพ SVG ทับกัน**
   - สาเหตุ: จัดวางพิกัดโดยไม่คิดถึงความยาวของข้อความ
   - แก้ไข: ขยายพื้นที่ภาพ จัดตำแหน่งป้ายใหม่ และย้ายป้ายจุด Q ไปใต้จุด
   - วิธีตรวจ: เปิดดูผลจริงในเบราว์เซอร์ก่อน commit ทุกครั้ง
6. **รัน Flask ซ้ำหลายตัวแล้วพอร์ต 5000 ค้าง**
   - สาเหตุ: มี VS Code debugger และ `flask run` ทำงานพร้อมกัน
   - แก้ไข: ปิด instance เก่าก่อนรันใหม่ หรือใช้พอร์ตอื่น (`--port 5050`)
